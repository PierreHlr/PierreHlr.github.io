The project

ECEPilot is a rover that can be driven remotely over Wi-Fi. A 360° LiDAR lets it perceive its surroundings, and an emergency stop can halt it at any time.

Architecture

The embedded system relies on three microcontrollers: an ATmega328P, an ESP32 and an ESP01S. The software side is built on ROS2.

The remote control

The remote control is a single-sided printed circuit board designed in KiCad. It combines a joystick, buttons, an OLED screen, a buzzer and an RGB LED.

The project has been under way since September 2026: this page will be updated as it progresses.
